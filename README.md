# 🏥 MediBuddy Insurance Data Analysis (EDA Project)

## 📌 Project Overview
This project focuses on performing **Exploratory Data Analysis (EDA)** on MediBuddy’s insurance dataset to identify key factors influencing medical insurance charges. The analysis helps in understanding customer behavior and supports better decision-making for insurance pricing and risk management.

## 📂 Dataset Description
The project uses two datasets:
- **Insurance Price Dataset** – Contains age, gender, BMI, and insurance charges.
- **Personal Details Dataset** – Contains number of dependents, smoking status, and region.

Both datasets were merged using **Python (Pandas)** based on a common column **Policy Number**.

## 📊 Exploratory Data Analysis Performed
The following visualizations and analyses were performed:

- Insurance charges distribution  
- Age distribution and age vs charges  
- Gender distribution and gender vs charges  
- BMI distribution and BMI vs charges  
- Smoker vs non-smoker comparison  
- Region-wise insurance analysis  
- Dependents vs insurance cost  
- Correlation heatmap  
- Pair plot for relationship analysis  

A total of **13+ charts** were used to analyze the dataset.

## 📌 Key Insights
- **Age, BMI, and smoking habits** strongly affect insurance charges.
- **Smokers** incur significantly higher medical costs.
- **Higher BMI** leads to increased insurance expenses.
- **More dependents** result in higher insurance claims.
- **Gender and region** have minimal impact on insurance pricing.
- Healthy individuals can be offered **discounted premiums**.

## 🎯 Business Impact
- Helps in **risk-based insurance pricing**
- Supports **better premium calculation**
- Assists in **customer segmentation**
- Enables **data-driven decision-making**
- Helps reduce financial risk for the company

## ✅ Conclusion
This project demonstrates how data analysis can be effectively used in the healthcare insurance domain. By analyzing customer attributes such as age, BMI, smoking habits, and dependents, meaningful insights were derived that can help MediBuddy improve policy design, pricing strategies, and overall business performance.
